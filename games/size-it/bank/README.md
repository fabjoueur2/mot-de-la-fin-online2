# Size Game Asset Bank

310 playable entries with local SVG assets.

Categories: {'geography': 177, 'standard_object': 73, 'sports': 30, 'space': 30}

Each record includes `id`, `name`, `category`, `dimension`, `trueSize`, `unit`, `svg`, `source`, `sourceUrl`, `license`, `assetStatus`, and `measurementMethod`.

Country sizes use the width of each Natural Earth silhouette's Equal Earth projected bounding box. This is deliberately a **game convention**, not a claim about an official country width.

All SVG paths are relative and work offline.
